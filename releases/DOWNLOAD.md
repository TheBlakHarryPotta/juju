# Sales Command for M1 Mac

Download `Sales-Command-M1-Release.zip` from this folder using GitHub’s download button. In Safari, stay signed into the GitHub account that can access this repository.

1. Extract the ZIP and open the `Sales-Command` folder.
2. Read `START-HERE.md`.
3. For local transcription, run `setup-mac.command`, then `start-mac.command`. Python 3.12+ and Apple Command Line Tools are required. The installer builds whisper.cpp for your Mac and attempts the official model download.

The native engine was built/tested on Linux in the cloud; the M1 build and actual speech recognition have not been benchmarked. The cloud network blocked model downloads. No speech model, credentials, local user database, or private pairing token is included.
