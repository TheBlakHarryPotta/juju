# Sales Command Mac app icon

[Download the Mac icon add-on](https://github.com/TheBlakHarryPotta/juju/raw/refs/heads/sales-command-download/releases/Sales-Command-Mac-Icon.zip)

Small standalone add-on: 260,557 bytes. SHA-256: `4e44be9dff52651f155f827dd7ee06928bc725a5291c0ecde6946e7434523d8c`.

Stop the old Terminal launcher with Control–C. Extract this ZIP, run **install-mac-icon.command**, and choose your existing installed **Sales-Command** folder. Finder reveals **Sales Command.app** in your personal Applications folder. Double-click it and keep it in your Dock.

Click to start both local services and open Safari. Quit Sales Command from the Dock to stop the services. The one-time installer uses Terminal; everyday use does not. Keep the installed data folder in its current location.
